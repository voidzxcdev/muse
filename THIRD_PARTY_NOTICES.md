## Riff — https://github.com/rootscripts/riff (commit 935ae2d)

Since build 319 Muse's web UI **is** Riff's renderer: layout, design, components,
animations, theme system, sound panel, player behaviour and the Web Audio engine
are Riff's own files, used 1:1. Muse swaps the name/logo, points Riff's local
`/api/*` calls at Muse's server, and adds accounts and chats styled with Riff's
components.

| Muse file | Riff source | Changes |
| --- | --- | --- |
| `web/public/riff/app.js` | `app.js` | small edits marked `Muse:` (generic views in `switchView`, mini mode only in Electron, name in strings, `window.museRiff` handle) |
| `web/public/riff/audio-engine.js` | `audio-engine.js` | license header only |
| `web/public/riff/styles.css` | `styles.css` | Google Fonts `@import` removed (fonts are self-hosted) |
| `web/index.html` | `index.html` | generated by `web/tools/riffify.py`: Muse head/branding, Muse views and dialogs inserted |
| `web/public/riff/LICENSE` | `LICENSE` | verbatim |

Muse-only files (not from Riff): `web/public/muse/bridge.js` (Riff's API on
Muse's server, stall/retry watchdog, iOS/Android/Linux shell glue),
`web/public/muse/social.js` (accounts, friends, chats), `web/public/muse/muse.css`,
`web/tools/muse-views.html`, `web/tools/muse-dialogs.html`.
